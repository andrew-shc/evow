# GREENFIELD/features

Runnable dashboard pages for future view, text selection, and text editing. Each page offers implicit and explicit modes and a collapsible execution flow. Outputs are data and belong under `ASSETS/features/`.

## Current baseline

These initial local pipelines use OpenCV and imageio while text–vision model dependencies are unavailable. Keep mode labels and flow records honest about their baseline implementation; replace the backend functions when trained model adapters are added.
